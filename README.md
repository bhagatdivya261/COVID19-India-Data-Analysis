COVID-19 India Data Analysis (Power BI)

Project Overview

This project presents an interactive Power BI dashboard analyzing COVID-19 data across India. It provides insights into case trends, state-wise distribution, recoveries, and deaths.

Key Insights

Daily Case Trend Analysis
State-wise Death Count
Top 10 States by Confirmed Cases
Cumulative Death Growth
Recovery Trends Over Time
Indian vs Foreign Cases Comparison

 Tools & Technologies

* Power BI
* Excel / CSV Dataset
* Data Cleaning & Visualization
